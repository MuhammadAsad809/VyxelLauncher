# VyxelLauncher

Modern Android launcher with iOS-style Liquid Glass UI.

## Features
- Home screen with glass dock and clock
- App drawer with installed apps
- Translucent glass materials (blur + refraction-style)
- Compose-based, Material 3
- HOME category launcher

## Tech
- Kotlin + Jetpack Compose
- minSdk 26, targetSdk 35
- Custom glass modifiers (ready for AGSL / Cloudy upgrade)

## Build
Open in Android Studio and run on device/emulator.

Set as default home app when prompted.
